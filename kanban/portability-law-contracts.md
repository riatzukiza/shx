- [ ] All current law/config and law/ir public schemas, recursive registry and validators load as `.cljc` on JVM, NBB and compiled shadow-cljs without JVM imports or inward extern dependencies; malformed/unknown inputs and empty/nonvector programs retain the existing validation outcomes.
- [ ] Exact open-map configuration, optional fields, enum guards, recursive forms, nonempty exec argv and explain/error payload contracts remain inspectable. A supplied-data corpus tests equivalent positive/negative decisions on both host families, rather than merely checking require success.
- [ ] Reconcile the separately proposed supervisor-ir-law shared Exec namespace with this port before editing the shared registry. Existing Exec stays authoritative until a reviewed replacement is qualified; do not copy a pending schema or create competing authorities.
- [ ] Forms-driven boundary verification discovers every selected portable namespace and reader branch; missing/empty discovery, an injected forbidden host require/import/interop and host-branch leaks fail. No copied Clio checker or broad suppression becomes a new unreviewed authority.
